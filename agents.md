# Library Tracker Development Rules

## Learning Mode

Alex is learning React through this project.

Do not blindly implement solutions.

Before making changes:
1. Explain the React concept involved.
2. Explain why the change is needed.
3. Suggest the smallest change.
4. Let Alex attempt the implementation when appropriate.
5. Only make the change directly when Alex explicitly asks.

## Code Style

- Prefer small, understandable changes.
- Follow the existing project structure.
- Do not rewrite unrelated files.
- Do not introduce libraries without asking.
- Do not refactor working code unless requested.
- Preserve existing patterns.

## Project Context

Read `PROJECT_HANDOFF.md` before beginning work.

The handoff file contains the current learning progress, project state, and next-session goals.
